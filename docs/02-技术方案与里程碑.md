# 技术方案与里程碑

## 1. 架构总览

```
┌───────────────────────────────────────────────────────────────┐
│ UI 外壳（Qt6 Widgets，单进程原生）                             │
│  标签栏(DocumentTabs) · 工具岛(InkToolbar) · 设置页(SettingsPage) │
│  浮层：笔调色板(PenPalette) · 页面缩略图(PageGrid)             │
├───────────────────────────────────────────────────────────────┤
│ 文档层（MainWindow）                                           │
│  多文档：QStackedWidget 每文档一个 PdfCanvas + 底部标签栏       │
│  DocumentInfo{ canvas, sourcePdf, bundlePath, title }          │
├───────────────────────────────────────────────────────────────┤
│ 渲染层（PdfCanvas，QAbstractScrollArea）                       │
│  连续纵向页流 · 整页渲染 · 128 MB LRU · 锚点缩放 · 触控         │
├───────────────────────────────────────────────────────────────┤
│ 墨迹层（PdfCanvas 内）                                         │
│  按页存储 · 归一化坐标(0..1) · 粗细按页宽比例 · 撤销快照栈      │
├───────────────────────────────────────────────────────────────┤
│ 持久化层                                                       │
│  AnnotationBundle(.dpz: source.pdf + annotations.json)         │
│  PdfExport(注入 PDF：栅格化 + 烧录批注)                        │
└───────────────────────────────────────────────────────────────┘
```

## 2. 关键设计决策

| 主题 | 决策 | 理由 |
|---|---|---|
| 滚动形态 | **纵向连续滚动**（非幻灯片翻页） | 教师按"像 Word 一样顺着看"的直觉使用 |
| 渲染粒度 | **整页位图 + 有界 LRU** | 200 MB 预算内不需要瓦片，实现更简单 |
| 缩放 | **锚点缩放**（横纵都补偿） | 捏合时以两指中心为锚点，视野不漂 |
| 缩放中的重渲 | 手势中**只拉伸已有位图**，停下 160 ms 再重渲 | 避免每次触摸事件都清缓存 → 卡顿 + 内存抖动 |
| 墨迹坐标 | **页面归一化 (0..1)** | 滚动/缩放/分辨率变化零漂移 |
| 墨迹粗细 | **按页宽比例存储** | 放大时写的字，缩回后一起变小 |
| 采样 | **写入时插值补密**（阈值 0.25% 页宽） | 快速书写不断笔，擦除命中更精确 |
| 橡皮 | **局部切除**（把笔迹在该处切成两段） | "指哪擦哪"，不是整条删除 |
| 橡皮拖动 | **沿轨迹扫掠 + 跳跃保护**（>40 px 视为丢事件，只擦落点附近窗口） | 快拖不漏、又不会一次擦掉一大段 |
| 触摸与书写 | 出现第二触点即**锁书写**，全部抬起后解锁；**鼠标路径同样受锁约束** | 触摸常被同时转发为合成鼠标事件，只锁触摸路径无效 |
| 浮层 | 一律为视口内的**子控件**（不用顶层 Popup） | 无边框顶层窗口会被系统加一圈**方形**原生阴影 |
| 浮层关闭判定 | 按**事件坐标**而非"投递给了哪个控件" | 画布接受触摸事件，会把浮层上的点击也报给全局过滤器 |
| 撤销 | 全网**快照栈**（墨迹数据很小） | 简单、可靠；每次变更前先快照 |

## 3. 内存预算（3 文档 + 4K）

| 项 | 标准 (MB) | 精简 (MB) |
|---|---:|---:|
| 进程基线（Qt Widgets + D3D/D2D + CRT） | 45 | 45 |
| 引擎/文档态 ×3（xref、页树、字体，懒解析） | 30 | 24 |
| 整页位图 LRU（上限 128 MB） | 96 | 64 |
| 页面预览/缩略图 | 16 | 8 |
| 墨迹矢量 | 12 | 12 |
| 墨迹栅格/几何缓存 | 24 | 16 |
| 渲染暂存 | 24 | 16 |
| 交换链/显存（iGPU 共享内存） | 63 | 32 |
| **合计** | **~310** | **~217** |

> **实测**：单文档 25–27 MB；双文档 ~91 MB。真实使用远低于预算上限（因为非活动文档会释放位图）。

## 4. 里程碑与验收

| 里程碑 | 交付 | 验收标准 | 状态 |
|---|---|---|---|
| **M0 技术验证** | 打开 PDF、渲染一页、画一笔；测出基线与耗时 | 目标机实测：基线 ~24 MB、单页 16–60 ms | ✅ |
| **M1 单文档渲染内核** | 连续纵向滚动 + 视口按需渲染 + 整页 LRU + 锚点缩放 | 连续滚动流畅；单文档内存达标；`适配宽度` 保持焦点 | ✅ |
| **M2 墨迹与输入** | 墨迹模型 + 笔/橡皮/撤销 + 局部擦除 + 触控 | 快速书写不断笔；橡皮"指哪擦哪"；双指不误画 | ✅ |
| **M3 多文档** | 多标签 + 共享内存策略 + 缩略图跳页 | 多文档切换正确；非活动文档释放位图 | ✅ |
| **M4 持久化** | `.dpz` 打包保存 / 另存为（注入 PDF）/ 双击打开 | 保存后重开批注完整还原；注入 PDF 任何阅读器可开 | ✅ |
| **M5 布局与体验** | 工具岛 / 调色板 / 标签栏 / 设置页 / 深色适配 | 观感统一、触控目标足够大 | ✅ |
| **M6 部署** | 静默安装 exe + 文件关联 + 签名 | 集中管理客户端可静默下发 | ⏳ 待做 |

## 5. 明确不做（避免与商业白板软件正面竞争）

课件创作、课堂活动、思维导图、学科工具全集、题库、云课件、账号体系、AI 备课、视频展台、答题器、手机遥控。

## 6. 已知风险

| 风险 | 对策 |
|---|---|
| 红外屏不产生原生手势 | 已改为**直接读取多点触摸事件**，不依赖系统手势 |
| 触摸被同时转发为鼠标事件，导致误画 | 书写锁 + 鼠标路径拦截 + 短笔画过滤 + `TouchCancel` 丢弃 |
| 高倍放大时单页位图过大 | 上限 48–100 MB 自动降采样 |
| 注入 PDF 丢失文本层 | 已在 README 说明；如需保留可选装 PDFium 写入接口 |
